Student: Mohamed Osama
Assignment branch: `assignment/1-5`

This repository contains the four required parts of the Simulation Academy Backend .NET OOP assignment.

## Projects

- `Part1_ProceduralToOOP` converts the supplied procedural C++ order system into an object-oriented C# console application.
- `Part2_HotelReservationSystem` models hotel guests, rooms, and reservations with strict encapsulation and validation.
- `Part3_BuilderPattern` demonstrates both a fluent invoice builder and composed address/order builders.
- `Part4_LeetCode/1679_MaxNumberOfKSumPairs` contains the required C# two-pointer solution.

## Build

Run `dotnet build` from each Part 1-3 project folder. Part 4 is a LeetCode submission file rather than a standalone project.
